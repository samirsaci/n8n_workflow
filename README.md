- ⏰ [**Productivity for Business Professionals and Students**](./Productivity)
- ✍️ [**Content Creation, Promotion and Marketing**](./Content_Creation)
- 🌳 [**Automation for a More Sustainable World**](./Sustainability)
- 🚛 [**Logistics & Supply Chain Automation**](./Supply_Chain)
- 🧑‍💻 [**Programming & DevOps**](./DevOps)

Each workflow is:

- **Ready to deploy** (JSON export included)
- **Documented** (clean README inside each folder)
- **Modular & reusable**
- **Explained in a YouTube tutorial** when available

## 📁 Repository Structure

Each workflow has its own folder:

```
/workflow-name/
├── workflow.json # Import directly into n8n
└── README.md # Full presentation + setup instructions
```
