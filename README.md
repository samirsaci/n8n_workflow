- ✍️ [**Content Creation, Promotion and Marketing**](./Content_Creation,_Promotion_and_Marketing)
- 🌳 [**Automation for a More Sustainable World**](./Automation_for_a_More_Sustainable_World)
- 🚛 [**Logistics & Supply Chain Automation**](./Logistics_%26_Supply_Chain_Automation)
- 🧑‍💻 [**Programming & DevOps**](./Programming_%26_DevOps)

Each workflow is:

- **Ready to deploy** (JSON export included)
- **Documented** (clean README inside each folder)
- **Modular & reusable**
- **Explained in a YouTube tutorial** when available

## 📁 Repository Structure

Each workflow has its own folder:

```
/workflow-name/
├── workflow.json # Import directly into n8n
└── README.md # Full presentation + setup instructions
```
