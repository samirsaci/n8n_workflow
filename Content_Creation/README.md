# ✍️ Content Creation, Promotion and Marketing — n8n Workflows

This folder contains all workflows dedicated to **content creation**, **blog promotion**, **SEO automation**, and **marketing workflows** powered by **n8n**.

These templates help automate repetitive creative tasks such as:

- Generating LinkedIn posts from blog articles
- Automating SEO audits and improving image accessibility
- Producing newsletters and content digests
- Extracting and transforming media assets
- Connecting Ghost, Google Sheets, Gmail, Photoroom API, and GPT models

All workflows are:

- **Ready to deploy** in n8n (JSON included)
- **Documented** with their own README
- **Modular and customizable**
- Most of them include **YouTube tutorials** for step-by-step guidance
